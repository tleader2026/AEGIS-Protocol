# Security Policy

AEGIS is a draft protocol site and specification. Please report security issues privately before public disclosure.

## Reporting

Open a private security advisory in GitHub or contact the maintainers listed by the repository owner.

## Areas of Interest

- Incorrect cryptographic assumptions
- Replay or downgrade risks in packet examples
- Confused deputy risks in intent delegation
- Privacy leakage in semantic lineage examples
- Broken validation or tamper-detection behavior
- Supply-chain issues in the developer portal

## Supported Versions

Until a formal release process exists, security review applies to the default branch.
