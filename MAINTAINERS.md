## Maintainer Expectations

Maintainers are expected to:

- preserve the distinction between AEGIS provenance and downstream governance systems
- require tests or fixtures for behavior changes
- keep schemas, conformance profiles, SDKs, and examples aligned
- avoid vendor-specific assumptions in normative protocol text
- document architecture decisions in `/adrs`

## Becoming a Maintainer

Maintainer status is earned through sustained, high-quality contributions to specifications, SDKs, conformance fixtures, runtime components, or security review.

Future maintainers should be added by pull request with the approval of existing maintainers.
