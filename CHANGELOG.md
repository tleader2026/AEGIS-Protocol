## 0.1.0-draft

### Added

- `FRAMEWORK.md` explaining the philosophical, technical, geopolitical, and protocol foundations.
- `ProvenanceEnvelope` schema.
- AEGIS conformance profiles for MCP, A2A, and ACP.
- JSON-RPC runtime handshake draft.
- Python MVP for metadata objects, runtime daemon, transport implementations, and JSONL record store.
- C core primitive with stable ABI surface.
- Kernel/hardware MVP plan and cross-platform runtime daemon launch templates.
