# AEGIS Specification

This directory contains the formal AEGIS protocol specification.

AEGIS is the Adaptive Execution & Governance Integrity Standard. It defines how accountable agent execution produces verifiable provenance records across transport protocols such as MCP, A2A, and ACP.

## Documents

- [Protocol Specification](./protocol.md)
- [Python Prototype Plan](./python-prototype.md)

## Maturity

The current specification is `1.0-draft`. It is not yet candidate standard. Candidate status requires:

- a complete Python reference implementation
- passing conformance tests
- at least one transport implementation producing valid `ProvenanceEnvelope` records
- stable JSON Schemas
- documented security model
