# Examples

Examples are non-normative protocol fixtures used for documentation, demos, and future conformance tests.

Current examples:

- `supervised-remediation.manifest.json`: supervised infrastructure remediation with intent, runtime evidence, human approval, provenance, and impact receipt.
- `packets/identity-hello.packet.json`: initial identity handshake packet.
- `packets/intent-present.packet.json`: signed intent presentation packet.
- `packets/execution-checkpoint.packet.json`: runtime checkpoint packet.
- `packets/registry-reconcile.packet.json`: registry reconciliation packet.
